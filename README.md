## Featured projects

### [Ukraine Dairy Research](https://github.com/mcharniuk1-spec/dairy_research) · Economics & data analysis

**Question:** How do prices move through Ukraine's dairy value chain, and what can those movements tell us about possible market power?

**Approach:** The research combines farm-gate, processor, public procurement and retail data. Python pipelines clean and align the data, check units and product definitions, and build econometric models of price relationships and adjustment. The analysis separates evidence of price adjustment from claims about market power.

**Explore it:** Start with the [final model package](https://github.com/mcharniuk1-spec/dairy_research/tree/main/newmodel), which contains the thesis draft, data, model tables, figures and reproducible scripts. The supporting [retail scraper](https://github.com/mcharniuk1-spec/scraper), [Prozorro data collector](https://github.com/mcharniuk1-spec/prozzoro), [Qlik export](https://github.com/mcharniuk1-spec/qlik), and [Silpo experiments](https://github.com/mcharniuk1-spec/silpo1) help show how the evidence was assembled.

### [ArchFlow Knowledge Operator](https://github.com/mcharniuk1-spec/archflow_b1_knowledge) · Knowledge systems & AI agents

**Problem:** Research, decisions and project context often get scattered across documents, tools and conversations.

**Approach:** ArchFlow organizes work into a research → define → act → review → remember loop. Its public, local-first kit brings together bounded evidence, role and skill definitions, validation, review and maintained knowledge. The dashboard makes the process visible; its public core runs without an API key.

**Explore it:** Follow the repository's quick start to run the dashboard locally. The result is a practical way to prepare and inspect work packets, with documented checks and clear boundaries around optional integrations.

### [M2 Lab Radar / Content Creator](https://github.com/mcharniuk1-spec/content_creator) · Content intelligence & collaboration

**Problem:** Find useful creative patterns in short-form content without relying only on raw view counts.

**Approach:** This collaborative project collects public Instagram Reel metrics, compares each post with its creator's own baseline, and analyzes selected videos through frames, transcription and topic tags. It turns the shortlist into shooting cards for people to review and develop.

**Explore it:** The [repository](https://github.com/mcharniuk1-spec/content_creator) explains the research-to-production workflow and how to run it. Its outputs are a shortlist, analysis and creative prompts—not a substitute for human editorial judgment. I also participated in work on the shared M2 Lab Radar project.

### [Polymarket Analytics](https://github.com/mcharniuk1-spec/polymarket) · Market research & decision support

**Problem:** Bring market data, context and uncertainty together when examining prediction markets.

**Approach:** This research MVP uses public, read-only market data and a multi-agent workflow to organize context, model outputs and paper decisions across macroeconomics, politics and stocks/trade. It includes a local dashboard, simulated portfolios and risk controls.

**Explore it:** Run the local workflow or dashboard using the repository's quick start. It produces research reports and paper-trading records; it does not place bets or connect a wallet.

### [Reallystate](https://github.com/mcharniuk1-spec/reallystate) · Real-estate product & data infrastructure

**Problem:** Make fragmented Bulgarian property information easier to organize and assess.

**Approach:** The MVP combines a source registry, standardized listing ingestion, duplicate scoring, property models and publishing eligibility checks. The repository also contains architecture, a roadmap, schemas and tests.

**Explore it:** Use the repository's setup guide to inspect the source registry, run the tests and explore the ingestion workflow. It is an evolving platform foundation, with further source connectors and infrastructure described in the roadmap.
